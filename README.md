# libft

42서울 라피신 과정에서 진행한 C 언어 과제

## 개요

C 언어의 기본 문법과 표준 라이브러리 함수의 동작 원리를 학습하고, 주요 함수의 기능을 직접 구현하며 프로그래밍 기초 학습

## 학습 내용

- **C 언어 기초**: 변수, 자료형, 조건문, 반복문, 함수 및 포인터 활용
- **문자열 처리**: 문자열 탐색, 비교, 복사 및 조작
- **메모리 관리**: 메모리 초기화, 복사 및 동적 메모리 할당 관련 함수 이해
- **함수 구현**: 기존 라이브러리 함수의 동작 원리를 분석하고 직접 구현
- **컴파일 및 빌드**: C 소스 코드 컴파일과 Makefile을 활용한 빌드 과정 학습

## 기술 스택

- Language: C
- Build: Makefile
- Environment: 42서울 라피신
